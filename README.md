# 🐹 芝芝闯迷宫

一款可爱的迷宫闯关游戏，玩家控制仓鼠"芝芝"在迷宫中收集食物、躲避猫咪敌人，最终到达出口通关。

## 🎮 游戏玩法

- **目标**：收集所有食物，躲避猫咪，找到出口
- **操作**：使用方向键或虚拟按键控制仓鼠移动
- **规则**：必须吃完所有食物才能通过终点

## ✨ 特色功能

- 📱 **移动端支持**：适配手机和平板电脑触控操作
- 🎯 **三关难度递增**：迷宫复杂度逐步提升
- 🍇 **食物收集系统**：实时显示已获取食物数量
- 🐱 **敌人巡逻机制**：猫咪在固定范围内巡逻
- 💖 **生命值系统**：吃到食物恢复体力，被猫咪攻击减少体力
- 🚪 **通关条件**：必须收集完所有食物才能通过终点

## 🚀 快速开始

### 在线游玩
直接访问 GitHub Pages 网站即可游玩。

### 本地运行
```bash
# 克隆仓库
git clone https://github.com/你的用户名/hamster-maze-game.git

# 进入目录
cd hamster-maze-game

# 使用浏览器打开
# 方式1：直接用浏览器打开 index.html
# 方式2：使用本地服务器
python -m http.server 8000
# 然后访问 http://localhost:8000
```
